==========================================
  仿真模拟器 —— 演示版（功能完整 · 免授权）
==========================================

在真机到货之前，这台电脑就是你的储能电站。

一、5 分钟快速体验
------------------
1) 启动：Windows 双击 start.bat；macOS/Linux 运行 ./start.sh
   （启动后会自动打开浏览器，也可手动访问 http://127.0.0.1:5050）
2) 看到「主电气接线」：2 单元储能电站正在运行，PCS 自动启动。
3) 试试命令（终端窗口直接输入）：
      esscmd setbms1 power on        # BMS 直流并网
      dpc simEmu1.yx3 set 1          # PCS1 启动
      dpc simEmu1.yt0 set 1000       # 有功 100 kW（会看到功率爬坡）
4) 打开「组态编辑」：已有示例电站，可拖拽节点、改参数、用向导生成新拓扑。
5) 连 Modbus（任意外部工具，如 mbpoll / Modbus Poll）：
      simEm  电表 端口 1500
      simBms1 BMS  端口 1501
      simEmu1 EMU  端口 1601

四、常见问题
--------------
- Modbus 连不上？等终端出现「协议服务就绪」后再连；检查端口未被占用。
- 功率不爬坡？确认已按上面的顺序：BMS 并网 → PCS 启动 → 再下功率。
- 改了组态点「应用」后程序退出？系统配置会重启后端，等待几秒后重新打开网页即可。
