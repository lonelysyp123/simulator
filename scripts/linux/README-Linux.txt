EssSimulator - Linux 快速说明
================================

完整使用说明请阅读同目录下的 README.txt。

快速启动
--------
1. 解压 EssSimulator-linux-*.tar.gz
2. chmod +x EssSimulator start.sh && ./start.sh
3. 等待协议服务就绪后使用 GUI 或 Modbus 联调

默认 Modbus 端口：电表 1500，BMS1 1501，EMU1 1601（详见 README.txt）

详细说明见 README.txt；技术手册见 docs/OperationManual.md（若已随包提供）
