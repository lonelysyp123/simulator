# 仿真模拟器 — 系统设计说明

## 1. 项目目标

- **仿真范围**：储能系统（ESS）端到端仿真——多路电池堆（Rack）、多台 PCS、主/单元断路器、主变/单元变、计划负载；通过 Modbus TCP 对外提供 BMS、EMU、电表等接口，供 EMS/主站联调。
- **可扩展性**：点位映射（CSV）+ `appsettings.json` 参数化；`DataExchange` 点目录驱动遥测/控制；支持多单元拓扑扩展。
- **对外名称**：仿真模拟器；工程名：EssSimulator。

## 2. 技术栈

| 类别 | 选型 | 用途 |
|------|------|------|
| 运行时 | .NET 8 | 主程序、自包含发布 |
| 宿主 | ASP.NET Core + `IHostedService` | Web、后台仿真、Modbus |
| 前端 | Vue 3 + Element Plus + Vite | 浏览器操作界面（`Web/src/`） |
| 实时 | SignalR | 主接线/电池/日志推送 |
| 协议 | NModbus 3.x | Modbus TCP 从站 |
| 配置 | `appsettings.json` + CSV 点表 | 拓扑、电气参数、Modbus 映射 |
| 日志 | log4net | 文件/控制台日志 |
| CSV | CsvHelper | 点表加载 |
| 测试 | xUnit | `EssSimulator.Tests/` |

## 3. 架构总览

```
┌─────────────────────────────────────────────────────────────┐
│  协议层：ModbusSimServer / DataExchangeSession              │
│  LC 转发：LocalControl/（可选，Modbus 聚合，不绑定仿真）       │
│  映射层：EssSimModelApi (PcsMapper, BmsMapper, EmMapper)    │
└───────────────────────────┬─────────────────────────────────┘
                            │ 对象路径 / ControlEffect
┌───────────────────────────▼─────────────────────────────────┐
│  编排层：EnergyStorageSystem（Host 时钟）+ PlantEngine.Step        │
│  求解层：ElectricalNetwork + NetworkSolver（AC 潮流主路径）         │
│  热/耦合：PlantThermalSystem + PlantCouplingGraph（PCS↔BMS）        │
│  传播层：RadialPowerSweepEngine（可选 Q-U 迭代）                   │
│  桥接层：NetworkControlBridge / NetworkStepOrchestrator             │
└───────────────────────────┬─────────────────────────────────┘
                            │ 共用设备实例
┌───────────────────────────▼─────────────────────────────────┐
│  设备层 EssDeviceSimModel/Devices/*                           │
│  PcsDevice · TransformerDevice · BreakerSimulator             │
│  GridSimulator · LoadDevice · MeterSimulator · BmsRackDevice  │
└─────────────────────────────────────────────────────────────┘
```

### 3.1 设备模型

| 设备 | 说明 |
|------|------|
| `PcsDevice` | 有功/无功爬坡、并网/离网、黑启动 V/f、直流/交流换算、保护 |
| `TransformerDevice` | 一二次电压/电流、铁损铜损、励磁涌流 |
| `BreakerSimulator` | 主断/单元断合分，网络控制面 SSOT |
| `GridSimulator` | PCC 无功—电压反馈 |
| `LoadDevice` | 35 kV 负载计划功率 |
| `BmsRackDevice` | BMS Rack 与 DC 端口、保护评估、并网链路 |
| `BatteryRackSimulator` | 电芯/簇/堆物理（`EssDeviceSimModel/Battery/`） |

### 3.2 关键设计原则

- **单一实例**：`ess._pcsList`、变压器、断路器与 `ElectricalNetwork` 内设备为同一对象。
- **Solver 主路径**：每 tick 由 `NetworkSolver.Step` 驱动 AC 段；PCS 物理在 `PcsDevice.Update` 完成 DC 耦合。
- **控制面**：断路器、负载计划、BMS 链路等经 `NetworkControlBridge` 写入网络。
- **BMS 保护**：`BmsRackProtection` 簇级三级告警状态机；堆级 `SystemAlarms` 可经 Modbus 读写。

## 4. 数据流与线程

### 4.1 仿真主循环（`EnergyStorageSystem`）

固定步长（`PropagationIntervalMs`，默认 100 ms）：

1. `PlantEngine.Step` — 电气潮流 → 热网络 → PCS/BMS 耦合
2. `NetworkStepOrchestrator` / `RadialPowerSweepEngine` — 控制意图与网侧回写
3. Mapper 独立周期刷新 DTO；Modbus DataExchange 读写寄存器

操作界面为浏览器（见 [B/S 架构说明](./B-S架构说明.md)），与仿真同进程。组态工程可生成 `configs/topology/generated/runtime-overlay.json`，工程模式启动时覆盖 `EssUnits` 等节。

### 4.2 Modbus 数据交换（`DataExchangeSession`）

适用于 **simEmu\*** / **simBms\*** / **simEm**：

| 管道 | 方向 | 说明 |
|------|------|------|
| 遥测 | 模型 → Modbus | 周期读 DTO，变更才写（Shadow 去重） |
| 控制 | Modbus → 模型 | FC5/6/16；`ControlEffect` 触发启停、黑启动、BMS 链路等 |
| 反馈 | 模型 → Modbus | 控制线圈/寄存器状态回写 |

**重连**：`link on` 后清空遥测 Shadow 并全量刷新，避免寄存器重建后读数为 0。

### 4.3 电气传播（`UseElectricalPropagation=true`）

`RadialPowerSweepEngine` 五相：叶子汇报 P/Q → 690V/35kV 汇总 → Grid Q-U → Coupler 传播 → 由 P/Q+V 算电流。

黑启动 PCS 作为 `BUS_690` 本地电压源（`IBusVoltageSource`）。

## 5. 配置与点表

- **点表 CSV**：`Address` / `FunctionCode` / `ParamName` / `Scale` / `ModelSim` / `Type`
- **运行配置**：`appsettings.json` — 见 [appsettings 字段说明](./appsettings.explained.md)
- **设备工厂**：`PcsDeviceFactory`、`TransformerDeviceFactory` 等
- **点表解析链路**（`PointMapPathResolver`）：运行时按固定文件名（`emu.csv` / `em.csv` /
  `bms_bank.csv` / `bms_rack.csv` / `lc.csv`）解析，优先级：
  1. **设备型号选型**：`pointmaps/models/{设备类型}/{型号}/` 下选中型号的点表
     （`DeviceModelRegistry` 扫描目录；选型持久化于 `configs/topology/device-models.json`，
     Web 系统配置页切换，重启生效）
  2. 工作目录 / 输出目录根下的同名文件（发布 / sync 脚本复制结果）
  3. `pointmaps/models/{设备类型}/standard/` 及其他型号目录（开发兜底）

`ModelSim` 列含义：

- `model=4|arg1=...`：绑定仿真 DTO 路径，遥测由模型刷新，控制可走 DataExchange。
- `model=sum|arg1=<路径A>|arg2=<路径B>`：遥测值 = 路径A + 路径B（只读，仅 FC3/4；缺失/非数值操作数按 0）。
- `0` 或空：固定值/占位，**不绑定模型**；`dpc set` 可能被下一周期覆盖或无法持久改变物理量。

## 6. 目录结构（源码）

| 路径 | 职责 |
|------|------|
| `EssDeviceSimModel/` | 物理模型、主循环、网络求解 |
| `EssSimModelApi/` | BMS/EMU/电表 DTO 与 Mapper |
| `DataExchange/` | 点目录、遥测/控制/反馈管道 |
| `Protocol/` | Modbus 从站、`ModbusHostedService` |
| `Display/` | 命令解析与状态读取（无 TUI） |
| `Web/` | ASP.NET 端点、组态、快照；前端源码 `Web/src/` |
| `Configuration/` | 配置类型定义（含 Edition / License / Web） |
| `configs/` | 社区版/商业版/定制版/演示版 appsettings 模板 |
| `Licensing/` | 商业版机器码校验 |
