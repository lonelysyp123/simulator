## 2. 本次测试范围

| 编号 | 测试项 | 触发方式 | 监控方式 | 验收标准 |
|------|--------|----------|----------|----------|
| TC-R01 | BMS bank 系统簇过压三级故障（yx5） | GUI `dpc` / 脚本写线圈 | mbpoll 读 **同一点** bank 线圈 | ΔT ≤ 700 ms |
| TC-R02 | PCS 低压断路器开合（yx1） | GUI `dpc` / 脚本写线圈 | mbpoll 读 **同一点** EMU 线圈 | ΔT ≤ 700 ms |
| TC-R03 | BMS rack 总电压过压三级门限（yt4） | 脚本写保持寄存器 | mbpoll 读 **同一点** rack 寄存器 | ΔT ≤ 700 ms |
| TC-R04 | EMU 单元1功率因数设定（yt2） | GUI `dpc` / 脚本写寄存器 | mbpoll 读 **同一点** EMU 寄存器 | ΔT ≤ 700 ms |

**计时规则**

| 符号 | 含义 |
|------|------|
| T0 | GUI「命令输入」中 dpc 回显时间戳（`HH:mm:ss.fff`） |
| T1 | mbpoll 监控终端**首次**读到与预期一致的值（线圈 0/1 或寄存器 raw 值） |
| ΔT | T1 − T0（含约 ±50 ms 轮询误差） |

**同点原则**（TC-R01～R04）：触发点位与 mbpoll 监控点位必须一致（改哪个点、读哪个点），不跨 bank/rack 做联动观测。

**控制→反馈原则**（TC-R05～R06）：mbpoll 写 **控制点**（启停线圈 yx3），监控 **仿真器反馈点**（运行状态 yc44，由 PCS 模型经 PcsDataServer 同步）。记录两个延迟：

| 符号 | 含义 |
|------|------|
| ΔT_coil | T0 写线圈后，yx3 读回与命令一致的时刻（Modbus 控制层） |
| ΔT_status | T0 写线圈后，yc44 首次达到预期运行状态码的时刻（**仿真器控制响应**，主验收指标） |

### 3.1 BMS rack 从站号说明

BMS 主站 `slave=1` 对应 `bms_bank.csv`；**rack 簇 n** 对应 **slave = n + 1**：

| Rack 簇 | mbpoll `-a` | 说明 |
|---------|-------------|------|
| 簇 0 | **2** | 第 1 个 rack 从站 |
| 簇 1 | **3** | 第 2 个 rack 从站 |
| 簇 k | k + 2 | 以此类推 |

本报告 **TC-R01** 使用 **bank 主站 slave 1**；**TC-R03** 使用 **rack 簇 0 → slave 2**（BMS bank 主站无 FC6 遥调点，模拟量选用 rack 遥调寄存器）。

|----|------------|------------|

**yc44 状态码**（与 GUI「设备状态」一致）：0 停机 · 1 待机 · 2 故障 · 3 充电 · 4 放电

**50 ms 双点监控（终端 B，测试前启动）：**

```bash
while true; do
  date '+%H:%M:%S.%3N'
  echo -n "yx3="; mbpoll -0 -t 0 -a 1 -r 1003 -c 1 -p 1601 -1 -q 127.0.0.1
  echo -n " yc44="; mbpoll -0 -t 3 -a 1 -r 10053 -c 1 -p 1601 -1 -q 127.0.0.1
  sleep 0.05
done
```

**测试前条件**

| 检查项 | 要求 |
|--------|------|
| 单元高压断路器 yx0 | **1**（合闸） |
| 并网点 / 主网 | 有网（GUI 主接线可见线电压） |
| 有功设定 yt0（可选） | 如 raw=500（50 kW），便于进入待机/充放电 |
| PCS 无锁存故障 | 启动前 yc44 ≠ 2 |

**理论路径**：mbpoll 写 yx3 → 控制线程(100ms) → `ApplyEmuCommands` → PCS 模型变位 → PcsDataServer(100ms) → **EMU DataWorker(100ms)** → yc44 可读（BMS 仍为 500ms）。**ΔT_status 预期 ≤ 300 ms 量级**（含轮询误差）。

**脚本代跑**：`python3 scripts/perf/run_tc_r05_pcs.py`

### 5.1 TC-R01 — BMS bank yx5 变位响应

#### 用例定义

| 项 | 内容 |
|----|------|
| 目的 | 测量触发 **bank yx5** 后，**同一点位**在 Modbus 上反映的延迟 |
| 触发点 | simBms1，slave **1**，yx5，地址 **1005**，端口 **1501** |
| 监控点 | **与触发点相同**（yx5 @1501/a1/1005） |
| 理论路径（dpc） | dpc 写模型 → DataWorker(500ms) → mbpoll 读到 |
| 理论路径（mbpoll 写线圈） | Modbus 控制线程(100ms) → 线圈可读 |
| 预期 ΔT | ≤ **700 ms** |

#### 触发与复位

| 项 | 内容 |
|----|------|
| dpc 置位 | `dpc simBms1.yx5 set 1` |
| dpc 复位 | `dpc simBms1.yx5 set 0` |
| 映射路径 | `bms1.BatteryStacks[0].SystemAlarms.OvervoltageFault` |
| 脚本代跑 | `python3 scripts/perf/run_tc_r01.py`（mbpoll 写 addr 1005，监控同址） |

#### 操作步骤

1. 终端 B 启动 4.1 节 **yx5** 监控循环，确认初始值为 **0**。
2. GUI →「命令输入」，或运行代跑脚本。
3. 执行 `dpc simBms1.yx5 set 1`（或脚本写线圈），记录 **T0**。
4. 观察终端 B，记录 yx5 首次变为 **1** 的 **T1**，计算 **ΔT = T1 − T0**。
5. 执行复位 `dpc simBms1.yx5 set 0`，记录 yx5 回 **0** 的 ΔT（可选）。
6. 重复步骤 3–5 共 **3 次**。

> **代跑说明（2026-06-22）**：脚本 `run_tc_r01.py` 通过 mbpoll 写 bank 线圈 addr 1005=1，**T0 为写线圈完成时刻**；监控点与触发点均为 **yx5（slave 1 @1005）**。GUI 手动测试时 T0 取 dpc 回显时间戳。

| 2 | 14:16:52.712 | yx5 set 1 | 14:16:52.743 | 31 | 31 | ☑通过 ☐失败 |
| 3 | 14:16:53.493 | yx5 set 1 | 14:16:53.525 | 32 | 37 | ☑通过 ☐失败 |
| **统计** | — | — | — | avg=**33** max=**37** min=**31** | avg=**34** | ☑通过 |

#### 现象描述

1. **触发与监控均为 bank yx5**，置位后约 **31–37 ms** 内 mbpoll 可读回为 1，复位同理，**满足 ≤700 ms**。
2. 本次代跑为 **mbpoll 写线圈** 路径（控制线程 ~100 ms 量级），延迟低于纯 dpc→DataWorker(500ms) 理论上限；若需测 dpc 完整路径，请在 GUI 命令输入手动执行 dpc 并保留 4.1 监控循环。

## 8. 附录

### 8.1 备用 / 故障排查

**TC-R01：yx5 无变位或 ΔT 过大**

- 确认监控与触发均为 **slave 1 / addr 1005**，勿误读 rack 从站。
- dpc 路径理论上限约 **500 ms**（DataWorker）；mbpoll 写线圈路径通常 **<100 ms**。
- 若 dpc 无回显，检查 GUI 是否已进入「命令输入」（主界面按 `C` 或 `:`）。

**TC-R02：yx1 无变位或 dpc 无效**

- 确认监控与触发均为 **slave 1 / addr 1001 / 端口 1601**。
- yx1 **ModelSim=0**，优先用 **mbpoll 写线圈**或脚本 `run_tc_r02.py` 测 Modbus 层延迟。
- 若需测绑定模型的断路器点位，可另立用例（如 yx0 高压断路器），须遵守同点原则，不与 yx1 混测。

**TC-R03：yt4 无变位**

- 确认 **slave 2 / addr 40004 / 端口 1501**，mbpoll 读写的 `-t` 均为 **4**（FC6 保持寄存器）。
- rack 从站号 = 簇号 + 1（簇 0 → slave 2）。

**TC-R04：yt2 无变位**

- 确认 **slave 1 / addr 40002 / 端口 1601**，`-t 4` 读写。
- raw 值需按 Scale 1000 换算（0.950 → 950）。

**TC-R05/R06：启动无响应或 yc44=2**

- 确认 **yx0=1**（单元高压合闸）、并网点有网；必要时写 **yt0** 有功设定。
- 启动后若 **yx3 被清 0**，为联锁保护（无网/单元高压分/黑启动条件不满足），非 Modbus 延迟问题。
- **yc44=2** 表示故障态，需先排除告警再测启动。
- 主验收看 **yc44（OperationStatus）**，不是 yx3 线圈读回。
