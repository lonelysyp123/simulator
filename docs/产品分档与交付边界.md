# 产品分档与交付边界

对外产品名：**仿真模拟器**。工程名：EssSimulator。  
本文固化三档商业发行物的定位、差异与交付边界，供销售/交付/发布对齐。实现细节见 [项目编译说明](./项目编译说明.md)。

---

## 1. 商业路径（概览）

```
社区版（本地评估） → 充值版（线上托管体验） → 定制版（项目私有化交付）
```

| 档位 | 典型场景 | 主收入关系 |
|------|----------|------------|
| 社区版 | 本地试用、联调评估、售前演示 | 获客（通常免费或低门槛） |
| 充值版 | 公网/内网托管实例，按时长或次数体验 | 体验转化（授权由运维侧控制） |
| 定制版 | 按项目拓扑与点表私有化部署 | 主收入（配置/点表/文档/支持） |

---

## 2. 三档差异（必须可感知）

| 维度 | 社区版 | 充值版 | 定制版 |
|------|--------|--------|--------|
| 配置模板 | `configs/社区版.appsettings.json` | `configs/充值版.appsettings.json` | `configs/定制版.appsettings.json` |
| 拓扑规模 | 2 储能单元（评估用） | 与社区版同规模 | 按项目完整拓扑 |
| 默认监听 | `127.0.0.1`（仅本机） | `0.0.0.0`（供反向代理/网关接入） | 按交付约定 |
| GUI | 默认开启 | 默认无头（`NoGui: true`），适合服务器 | 默认开启（可按项目改） |
| 点位表 | 商业发布固定 `pointmaps/common` | 同左 | 默认 common；项目另有点表时按交付清单替换 |
| 本仓库内授权 | 无 | **无**（充值/时长由仓外服务端或网关控制） | 无（合同与交付清单约束） |
| 随包说明 | `scripts/commercial/editions/社区版/README.txt` | `…/充值版/README.txt` | `…/定制版/README.txt` |

> **重要**：本仓库发布的是仿真进程与配置，**不实现计费扣费**。充值版的「可连多久、能否下控」由部署侧授权模块或网关策略保证；本地改 `appsettings.json` 只能改拓扑与监听，不能替代授权。  
> 接口与状态机约定见 [充值版授权网关约定](./充值版授权网关约定.md)。

## 3. 交付边界（定制版）

**默认包含**

- 约定拓扑的 `appsettings.json`（或等价配置）
- 约定版本的 Modbus 点表（文件名保持 `emu.csv` / `em.csv` / `bms_bank.csv` / `bms_rack.csv`）
- 对应平台自包含运行包（win-x64 / linux-arm64）
- 随包技术文档（`docs/`）与版本 `README.txt`

**默认不包含（需合同单列）**

- 非 `common` 点表方案的长期双轨维护
- EMS 侧策略开发、现场真机联调人天
- IEC61850 等协议扩展、HIL 对接
- 多实例编排平台、集中日志运维

**配置变更约定**

- 社区版 / 充值版：允许用户改配置做评估，但**不承诺**扩容后的性能与联调支持。
- 定制版：拓扑与点表变更走变更单；**开发主配置变更后**用下列脚本同步模板，再发布：

```bash
./scripts/commercial/sync-custom-from-root.sh   # 根 appsettings → configs/定制版（叠加 NoGui=false）
./scripts/commercial/check-edition-drift.sh     # 档位差异与单元数检查
```

若定制版是「已交付项目快照」、刻意与当前开发拓扑不同，不要盲目同步；在变更单中注明快照版本即可。

## 4. 发布检查清单

```bash
# 1) 定制版与开发主配置对齐（按需；项目快照勿盲同步）
./scripts/commercial/sync-custom-from-root.sh

# 2) 档位配置差异校验（社区本机 / 充值公网模板等）
./scripts/commercial/check-edition-drift.sh

# 3) 商业多版本打包（点表固定 common）
./scripts/commercial/publish-all.sh
```

- [ ] 社区版 `BindAddress` / `HttpBindAddress` 为本机回环
- [ ] 充值版监听为可托管模板，且 README / [授权网关约定](./充值版授权网关约定.md) 写明授权在仓外
- [ ] 定制版单元数与当前项目交付清单一致（或已用 sync 脚本对齐）
- [ ] 随包 `README.txt` 与本文档档位描述一致
