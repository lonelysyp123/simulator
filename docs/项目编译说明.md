# 项目编译与发布说明

说明如何编译 EssSimulator、各发布脚本的作用，以及 `dist/` 产物布局。

---

## 1. 前置条件

- **.NET 8 SDK**（开发编译）
- Bash（macOS/Linux）或 PowerShell（Windows 本机发布）
- 在项目根目录执行下列命令

```bash
# 本地调试
dotnet build
dotnet run --project EssSimulator.csproj
dotnet test
```

---

## 2. 两类发布路径

| 类型 | 脚本位置 | 输出目录 | 配置来源 |
|------|----------|----------|----------|
| **开发/联调** | `scripts/publish-*.sh` | `dist/win-x64`、`dist/linux-arm64` | 仓库根 `appsettings.json` |
| **商业多版本** | `scripts/commercial/` | `dist/{版本名}/{平台}/` | `configs/{版本}.appsettings.json` |

---

## 3. 开发联调发布（非商业）

### `scripts/publish-windows.sh`

- `dotnet publish` → Windows x64 自包含单文件
- 拷贝 `log4net.config`、`autotest.json`、启动脚本及 **`docs/`**；点位表从 `pointmaps/{版本}/` 复制（见下文）
- 输出：`dist/win-x64/`，并打 `EssSimulator-win-x64.zip`

**点位表版本**（第一个参数或 `POINTMAP_VERSION`，默认 `common`）：

```bash
./scripts/publish-windows.sh              # common
./scripts/publish-windows.sh lc
POINTMAP_VERSION=battery ./scripts/publish-linux.sh
```

可选：`common`、`lc`、`battery`。详见 [pointmaps/README.md](../pointmaps/README.md)。

### `scripts/publish-linux.sh`

- 同上，目标 RID 默认 `linux-arm64`（可用环境变量覆盖）
- 输出：`dist/linux-arm64/`，并打 `EssSimulator-linux-arm64.tar.gz`

```bash
./scripts/publish-windows.sh
./scripts/publish-linux.sh
RID=linux-x64 CONFIG=Release ./scripts/publish-linux.sh
```

### 平台辅助

| 目录 | 内容 |
|------|------|
| `scripts/windows/` | `start.bat`、`README-Windows.txt` |
| `scripts/linux/` | `start.sh`、`README-Linux.txt` |
| `scripts/osx/` | `start` 说明、`解除隔离.sh`、`README-macOS.txt` |

## 4. 商业发布（社区版 / 商业版 / 定制版 + 演示版）

公共逻辑在 `scripts/commercial/publish-common.sh`：

> **点位表**：商业发布根目录点表**固定**取 `pointmaps/models/*/standard` 型号，并携带完整 `pointmaps/models/` 供运行期选型。

| 函数/行为 | 说明 |
|-----------|------|
| `edition_config_file` | 解析 `configs/社区版.appsettings.json` 等 |
| `copy_runtime_files` | 复制 `log4net.config`、`autotest.json`、`docs/`；点位表固定 **standard** 型号（`pointmaps/models/*/standard/`） |
| `edition_readme_file` | 复制 `scripts/commercial/editions/{版本}/README.txt` |
| `ensure_dist_layout` | 创建 `dist/社区版`、`dist/商业版`、`dist/定制版` |
| 打 zip/tar | `dist/EssSimulator-{版本}-{平台}.zip` |

### 脚本一览

| 脚本 | 作用 |
|------|------|
| `publish-windows.sh` | 单版本 Windows x64 发布 |
| `publish-linux.sh` | 单版本 Linux 发布 |
| `publish-macos.sh` | 单版本 macOS 发布（默认 osx-arm64） |
| `publish-demo.sh` | **演示版**评估包（不在 `ALL_EDITIONS` 内） |
| `publish-all.sh` | 社区/商业/定制 × win+linux 批量发布 |
| `sync-runtime.sh` | **仅同步** 配置/点位表（固定 common）/文档，不重新 `dotnet publish` |
| `publish-windows.ps1` | Windows 本机 PowerShell 入口 |

### 版本与配置

| 版本 | 配置文件 | 典型用途 |
|------|----------|----------|
| 社区版 | `configs/社区版.appsettings.json` | 2 单元，本机评估（高级 UI 关闭） |
| 商业版 | `configs/商业版.appsettings.json` | 完整能力，需 `license.txt` |
| 定制版 | `configs/定制版.appsettings.json` | 完整拓扑（与根 `appsettings.json` 同步维护） |
| 演示版 | `configs/演示版.appsettings.json` | 免授权评估；`publish-demo.sh` 单独打包 |

分档权益见 [产品分档与交付边界](./产品分档与交付边界.md)。旧名 `EDITION=充值版` 映射为商业版；仓外托管见 [充值版授权网关约定](./充值版授权网关约定.md)。发布前建议：

```bash
./scripts/commercial/sync-custom-from-root.sh   # 按需：对齐定制版与开发主配置
./scripts/commercial/check-edition-drift.sh
```

### 常用命令

```bash
# 单版本
EDITION=社区版 ./scripts/commercial/publish-windows.sh
EDITION=商业版 ./scripts/commercial/publish-linux.sh
EDITION=定制版 ./scripts/commercial/publish-macos.sh

# 演示版
./scripts/commercial/publish-demo.sh

# 标准三档 × win+linux
./scripts/commercial/publish-all.sh
./scripts/commercial/publish-all.sh 社区版    # 仅社区版

# 只更新点表/配置（已发布目录）
./scripts/commercial/sync-runtime.sh
./scripts/commercial/sync-runtime.sh 社区版 win-x64
```

**Windows PowerShell：**

```powershell
$env:EDITION = "社区版"
.\scripts\commercial\publish-windows.ps1
```

## 5. dist 目录结构

```
dist/
├── 社区版/
│   ├── win-x64/
│   ├── linux-arm64/
│   └── osx-arm64/          # publish-macos.sh
├── 商业版/
│   ├── win-x64/
│   └── linux-arm64/
├── 定制版/
│   ├── win-x64/
│   └── linux-arm64/
├── 演示版/                 # publish-demo.sh
│   └── …
├── EssSimulator-社区版-win-x64.zip
├── EssSimulator-社区版-linux-arm64.tar.gz
└── …（各版本 × 各平台）
```

**开发联调**（非商业脚本）仍可使用扁平目录：

```
dist/win-x64/
dist/linux-arm64/
```

每个平台目录通常含：`EssSimulator` 可执行文件、`appsettings.json`、点表 CSV、`start.bat`/`start.sh`、版本 `README.txt`。

---

## 6. 与非商业脚本的差异

| 项目 | `scripts/publish-*.sh` | `scripts/commercial/` |
|------|------------------------|------------------------|
| 输出路径 | `dist/win-x64` 等 | `dist/{版本名}/{平台}/` |
| 配置 | 根 `appsettings.json` | `configs/{版本}.appsettings.json` |
| 版本数 | 单一 | 社区/商业/定制（演示版另脚本） |
| 压缩包名 | `EssSimulator-win-x64.zip` | `EssSimulator-{版本}-{平台}.zip` |
| 随包说明 | 平台 README | 版本 README + 平台 README |

## 8. 维护提示

- 改 `configs/*.appsettings.json` 或点表后，对已发布目录可只跑 `sync-runtime.sh`。
- 新增商业版本：在 `configs/` 增配置、在 `editions/` 增 README，并在 `publish-common.sh` 的 `ALL_EDITIONS` / `edition_config_file` 注册。
- 社区版随包说明见 `scripts/commercial/editions/社区版/README.txt`；技术文档见 [docs/README.md](./README.md)。
- 商业分档与交付边界见 [产品分档与交付边界](./产品分档与交付边界.md)；发布前跑 `scripts/commercial/check-edition-drift.sh`。
- 定制版与根配置对齐：`scripts/commercial/sync-custom-from-root.sh`（项目快照勿盲同步）。
- 充值版仓外授权协作： [充值版授权网关约定](./充值版授权网关约定.md)。
