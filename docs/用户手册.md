# 仿真模拟器 — 用户手册

面向 EMS/BMS/PCS 联调与测试人员。说明安装、启动、界面、Modbus 联调及常见问题；内部实现见 [系统设计说明](./系统设计说明.md)。

---

## 1. 产品简介

仿真模拟器在本地模拟电池、变流器、变压器、断路器及并网点电气行为，通过 **Modbus TCP** 提供与现场相近的遥测与控制接口，便于无真机或真机不足时完成主控联调。

- 对外名称：**仿真模拟器**
- 发布包为自包含程序，**无需单独安装 .NET 运行时**

## 3. 快速启动

### Windows

1. 解压整个文件夹（exe、配置、点表同目录）
2. 双击 `start.bat` 或运行 `EssSimulator.exe`
3. 等待 **协议服务就绪**，进入主菜单

### Linux

```bash
chmod +x EssSimulator start.sh
./start.sh
```

### 开发环境

```bash
dotnet run --project EssSimulator.csproj
```

| 文件 | 说明 |
|------|------|
| `EssSimulator.exe` / `EssSimulator` | 主程序 |

## 5. Modbus TCP 端口

在 `appsettings.json` → `Simulator.Protocol` 修改。常见默认：

| 设备 | 服务名 | 默认端口 | 点表 |
|------|--------|----------|------|
| 并网点电表 | simEm | 1500 | em.csv |
| BMS 第 N 路 | simBmsN | 1501+(N-1) | bms_bank.csv |
| EMU 第 U 单元 | simEmuU | 1600+U | emu.csv |

- 从站地址（Unit ID）一般为 **1**
- BMS 簇表从站：**1 + 簇序号**（见 `bms_rack.csv`）
- 默认监听 **127.0.0.1**；跨机联调需改绑定并放行防火墙

命令与 mbpoll 示例见 [指令详细说明](./指令详细说明.md)。

## 6. GUI 主菜单

| 菜单 | 作用 |
|------|------|
| 主电气接线 | 220 kV / 35 kV / 690 V 拓扑、PCS/BMS、P设/P实 |
| 电池堆簇信息 | 按 BMS 路号查看 SOC、电压、电流 |
| 电池单体信息 | 选定簇的单体电压 |
| 命令输入 | esscmd / dpc / breaker / dpctest |
| 连接信息 | Modbus 监听与客户端 |
| 日志信息 | 运行日志 |

**快捷键**

| 场景 | 按键 |
|------|------|
| 根菜单 | ↑↓ 选择，Enter 进入，Esc 退出程序 |
| 主接线 | Tab 切换表格/ASCII；`:` 或 `C` 临时命令；Esc 返回 |
| 临时命令 | Enter 执行；↑↓ 历史；Esc 清空 |

## 7. 典型联调顺序

```text
dpc simEmu1.yx0 set 1          # 单元高压合闸
esscmd setbms1 power on        # BMS 直流并网
dpc simEmu1.yx3 set 1          # PCS1 启动
dpc simEmu1.yt0 set 1000       # 有功 100 kW（Scale 10）
```

在主接线查看 **P设 / P实**，或用 mbpoll 读 `yc27` 等反馈点。

---

## 8. 无界面模式

```json
"Simulator": { "Runtime": { "NoGui": true } }
```

仍提供 Modbus；调试需 EMS/mbpoll 或改回 `NoGui: false`。

## 9. 常见问题

| 现象 | 处理 |
|------|------|
| Modbus 连不上 | 等协议就绪；查端口、防火墙、IP 绑定 |
| PCS 启停无效 | 查 yx0 合闸、BMS 并网、`esscmd setbms1 power on` |
| P实 为 0 | 确认 PCS 运行且并网；注意 Scale（100 kW → 写 1000） |
| dpc 功率差 10 倍 | 控制点写 **原始寄存器值**，非工程 kW |
| link 后 SOH 等为 0 | 重连后会刷新；仍异常则重启或查 [指令说明](./指令详细说明.md) |
| 改单元数无法启动 | 检查 JSON 语法、EssUnits、端口冲突 |
