# EssSimulator 授权（机器码 + license.txt）

## 流程

```
用户机器                              你（卖方）
────────                              ────────
1. 运行 get-machine-id 或
   EssSimulator --machine-id
2. 把 32 位机器码发给你  ──────────►  3. issue-license.py 生成 license.txt
4. 收到 license.txt 后放到 ◄────────  （密钥 + 机器码 + 到期日，默认 1 年）
   解压目录，启动软件
```

## 用户侧：获取机器码

```bash
# macOS / Linux
./scripts/license/get-machine-id.sh

# 或（已解压商业版后）
./EssSimulator --machine-id

# Windows PowerShell
.\scripts\license\get-machine-id.ps1
```

## 卖方侧：签发（私有，勿进社区包）

```bash
export ESS_LICENSE_SECRET='生产环境务必更换的长随机串'
# 与运行商业版进程的环境变量保持一致；若不设则使用代码内开发默认密钥

./scripts/license/issue-license.py <机器码> --years 1 -o license.txt
# 或指定到期日：
./scripts/license/issue-license.py <机器码> --expires 2027-07-28 -o license.txt
```

将 `license.txt` 发给用户，放到与 `EssSimulator` / `appsettings.json` 同级目录。

## 软件校验（启动时）

商业版 / 定制版（`Simulator.License.Required=true`）：

1. 读取运行目录（或程序目录）下 `license.txt`
2. 校验 HMAC 签名（密钥）
3. 解密/解析机器码与到期日
4. 与本机机器码比对
5. `到期日 >= 今天` 才允许启动

社区版 `Required=false`，无需 license。

本地开发根配置默认 `License.Required=false`，避免影响日常联调。

## 配置

```json
"Simulator": {
  "License": {
    "Required": true,
    "FileName": "license.txt"
  }
}
```

生产密钥：设置环境变量 `ESS_LICENSE_SECRET`（签发脚本与运行商业版进程须一致）。
